# Phishing-Email-Analysis

## Project overview

This project explores how to identify and investigate a suspected phishing email.

This project uses an example phishing email to show how to spot warning signs, identify risks and suggest ways to stay safe.

## Objectives

- Understand how phishing emails work.
- Identify common phishing indicators.
- Examine suspicious sender details and links.
- Assess potential security risks.
- Recommend ways to prevent phishing attacks.

## Project Type

Educational cybersecurity investigation using simulated email data.
